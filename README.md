# Smart Routing Using Fog Computing

## Project Overview

This project proposes a Smart Ambulance Routing System using Fog Computing and SUMO (Simulation of Urban Mobility). The system detects traffic congestion and generates alerts to support faster ambulance movement towards the hospital.

The project demonstrates how Fog Computing can be utilized for intelligent traffic monitoring and emergency vehicle routing in urban environments.

## Objectives

* Detect traffic congestion in real-time.
* Utilize Fog Node logic for local decision making.
* Simulate ambulance movement in an urban road network.
* Improve emergency response efficiency.
* Demonstrate intelligent routing concepts using SUMO simulation.

## How to Run

1. Open the project directory.
2. Ensure SUMO is properly installed and configured.
3. Run `run_simulation.py`.
4. SUMO GUI will start automatically.
5. Observe ambulance movement and traffic conditions.
6. Monitor congestion alerts in the Python console.

## Expected Output

* Traffic congestion detection.
* Fog alert generation.
* Ambulance route monitoring.
* Successful arrival of ambulance at the hospital.
